## Key decisions
- QA filtering strictness: **moderate** — keep `qa_aod` codes 0 (best quality) and 3 (1 neighbor cloud), drop everything else. Directly grounded in NASA's own documented guidance rather than an arbitrary threshold.
- Human-judgment pipeline steps use a `"NOT_SET"` placeholder pattern in `params.yaml`, enforced by a guard clause that raises an error — this generalizes cleanly if the pipeline is later rerun on a different region/time where the right threshold may differ.
- `data/interim/maiac_aod/` restructured into per-stage subfolders rather than one shared folder, to satisfy DVC's requirement that stage outputs not overlap.
- MERRA-2's coordinate-consistency check treats any mismatch as a hard failure, not a warning — same reasoning as the CPCB `status`-column gap: silent staleness/drift is worse than a stopped pipeline.
- CPCB station keep/drop staleness is a design problem, not a data problem — the fix is a review-check gate stage that catches when manual decisions fall out of sync with automated QC, not an attempt to automate the judgment call itself.
