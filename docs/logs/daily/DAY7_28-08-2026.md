## Key decisions
- **Buffer radius: 1km for roads and industrial land-use** -- consistent with WorldCover/NDVI/SRTM, matches MAIAC's native grid.
- **Power plant tag restricted to `power=plant` only** (not `power=generator`) -- generator nodes tag small/distributed backup generators everywhere and would corrupt "distance to nearest power plant" as a proxy for grid-scale point-source emissions.
- **Bbox split by feature sparsity, not a single bbox for everything** -- roads/industrial need a tight bbox (dense data, large bbox = server overload); power plants need a wide bbox (sparse data, cheap regardless of area, and genuinely need the wider search radius since the nearest grid-scale plant to a Delhi station is often outside Delhi itself).
- **Manual browser-based Overpass Turbo export**, not live API calls from either shell -- the only viable path given the egress allowlist; documented in task log 6 so a future re-extraction doesn't re-discover this from scratch.

## Data notes & gotchas
- **Road density (5.6-41.4 km/km²) looks high for a per-station 1km buffer but is plausible**: `highway=*` in OSM covers everything from motorways down to footways, service roads and parking-lot aisles, and dense Delhi colonies have very fine-grained road/lane mapping. All values are under the QC ceiling (50 km/km²), and the spatial pattern makes sense -- lowest at peripheral/rural stations (Najafgarh, Alipur), highest at dense urban ones (Patparganj, Jahangirpuri).
- **Industrial fraction matches known Delhi industrial geography** -- Okhla Phase-2 (52%), Narela (47%), Wazirpur (27%) are all recognized industrial estates; 19/42 stations show 0% (expected for residential-area stations).
- **`power=plant` in OSM conflates very different facility scales.** The nearest "power plant" to several stations came back as a "Bio-Gas Plant" or a solar farm, not a grid-scale thermal/CCGT station -- OSM doesn't distinguish scale via this tag alone. Real combined-cycle gas stations did show up too (Pragati-III, Rithala, IP Gas Turbine Station, BSES), so the feature isn't wrong, but "distance to nearest power plant" as currently computed may understate exposure to genuinely large point sources if a tiny biogas unit happens to be closer. Worth flagging for the manuscript as a measurement-validity caveat, same spirit as the NDVI January-gap note from the static_gee module.
- All nearest-power-plant distances came back under 8.2km -- well inside the 110km edge-effect threshold, confirming the wide bbox was more than sufficient (no station's true nearest plant risks being outside the download extent).
