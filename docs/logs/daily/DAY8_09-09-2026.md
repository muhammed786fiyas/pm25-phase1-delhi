## Key decisions
- **Season-intercept promoted over full season-specific fit** -- season-intercept captured nearly all of full season-specific fit's CV accuracy (overall LOOCV RMSE 0.267 vs 0.266) without the small-sample monsoon slope fragility (full season-specific fit uses only ~19 monsoon days per station). Full comparison in `data/interim/maiac_gapfill/calibration_variant_comparison.csv`.
- **Static-covariate-augmented pooled model rejected** -- for the 38-station shared-MERRA2-cell cluster, adding NDVI/land-cover/road-density/industrial-fraction/elevation as extra regressors gave essentially no CV improvement over MERRA2-only (0.2878 vs 0.2875 RMSE).
- **Confidence scoring uses leave-one-out CV on the pooled per-station model, grouped by season only for reporting** -- not a separate model fit per season -- so confidence describes how well the one real production model performs in each season.
- **Confidence merged into the main gap-filled output, not left as a separate lookup table** -- `confidence_bucket`/`confidence_rmse` populated for filled rows, `"observed"`/null for real MAIAC readings, so downstream modeling doesn't need a manual join.
- **Confidence bucket thresholds are empirical terciles of the RMSE distribution**, not fixed AOD-unit guesses, and get re-derived any time the underlying calibration model changes.
- Clarified two different downstream uses for the two confidence representations: `confidence_bucket` for an LME sensitivity analysis (refit excluding low-confidence filled days), raw `confidence_rmse` as a LightGBM feature (trees can find their own thresholds/interactions, so hand-picked cutoffs are less useful there than for a linear model).
