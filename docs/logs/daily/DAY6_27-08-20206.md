## Key decisions
- 1km buffer radius for all static covariates, matching MAIAC's native AOD grid scale
- WorldCover v200 (2021) over v100 (2020) — more accurate algorithm, confirmed still latest
- NDVI: nearest 5-day composite over seasonal median — preserves temporal fidelity for the Phase 1 validation run
- NDVI extraction uses fixed 5-day periods + batch `reduceRegions` instead of per-station-day looping — cuts ~15,330 potential GEE calls down to 73
- NDVI gap-fill cap set at 5 periods, based on the actual observed max fill distance in the fill-distance analysis (not guessed upfront)
- params.yaml restructured to nest by stage per sub-dataset (`static_gee_layers.<subdataset>.<stage>`), matching the `era5_blh` pattern, to stop unrelated params changes from dirtying unrelated DVC stages
- Output paths moved out of params.yaml into CLI args / dvc.yaml
- Single `scripts/datasets/static_gee/` folder for WorldCover + NDVI + SRTM, not split by sub-dataset
- SRTM kept as 3 scripts (extract/QC/finalize) for consistency, even though finalize is a near-no-op
