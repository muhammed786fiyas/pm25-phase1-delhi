## Key decisions
- Project memory should be updated whenever a real task/milestone completes, not just left in chat context — standing habit going forward, not something to be asked for each time.
- AOD preprocessing stays AOD-only (no PM2.5 awareness) until the explicit temporal alignment step, where the actual CPCB↔AOD join happens.
- Left join (CPCB as base), not inner join, for the CPCB↔AOD merge — preserves PM2.5 days with missing AOD for MERRA-2 gap-fill to handle later.
- Group MERRA-2 stations by shared grid cell instead of extracting per station — Delhi's station spread (~40km) is smaller than one MERRA-2 cell (~62km), so grouping cut GEE calls from 42 to 3.
- Determine MERRA-2 cell membership via GEE's own `pixelLonLat()`, reprojected to MERRA-2's native projection, rather than manually computing grid membership from documented spacing — avoids a silent misalignment bug if the assumed grid origin were wrong.
- Split MERRA-2 processing into 4 separate numbered scripts (map cells → raw extract → window+QC → aggregate) instead of one combined script, mirroring the CPCB pipeline's separation of QC from aggregation — keeps the slow GEE call isolated from cheap, easily-rerun pandas logic.
- All script configuration now loads from `params.yaml` per-script (via `--params`), not hardcoded — standing rule for all future pipeline scripts, with a matching `dvc.yaml` stage provided alongside each one.
