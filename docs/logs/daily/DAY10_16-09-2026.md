## Key decisions

- **Random-slope-AOD kept as a separate comparison variant, not a replacement for the primary model** -- it does not outperform the primary model on spatial-LOSO (see Results below), so the primary random-intercept-only equation stays the reported model for now. The project context doc's equation section is unchanged.
- **Not registered to the Model Registry** -- a different equation spec, not a diagnostic data variant, so mixing it into the primary model's version history would be actively misleading about which version is production-representative.
- **Random-slope variance-component reporting generalized rather than special-cased** -- `variance_component_rows()` works for any `cov_re` shape, so a future 3rd random effect (if ever added) wouldn't need another hardcoded reporting branch.

## Results

Fit (full data, 42 stations):

| | Primary (random intercept only) | Random-slope-AOD |
|---|---|---|
| logLik | -10134.4 | -10111.9 |
| AIC | 20320.9 | **20279.9** |
| BIC | 20516.1 | **20490.2** |
| Random-intercept variance | 0.0233 | 0.0239 |
| Random AOD-slope variance | n/a | 0.00184 |
| Intercept-slope covariance | n/a | -0.00224 |

The random-slope-AOD fit throws a `ConvergenceWarning: The MLE may be on the boundary of the parameter space` (converges fine per `result.converged`, but the 2x2 covariance estimate is right at a boundary -- expected with only 42 groups estimating a full unstructured covariance matrix, a known risk noted in `LME_Architecture_M0_A_B_C_SUMMARY.md` for the analogous airshed case). AIC/BIC both favor the random-slope model on the full-data fit despite the extra parameters.

Spatial-LOSO CV (out-of-sample, the number that actually matters for generalization):

| | Primary | Random-slope-AOD |
|---|---|---|
| R2 | **0.423** | 0.412 |
| within-R2 (Kawano) | 0.211 | 0.211 |
| RMSE | 0.638 | 0.644 |

**Random-slope-AOD does not improve out-of-sample performance** -- R2 is very slightly worse, within-R2 is unchanged, and the two known LOSO outlier stations are unaffected or slightly worse (5598: R2 -3.428 -> -3.299; 6934: R2 -1.444 -> -1.864). This confirms the reasoning from the earlier "Ideas" discussion: a held-out station under spatial LOSO gets no random-effect BLUP of any kind, whether intercept or slope, so this equation change cannot fix the land-use-extrapolation problem driving those two outliers -- the better full-data AIC/BIC reflects genuine within-sample fit improvement (stations really do differ somewhat in AOD sensitivity), but that extra flexibility doesn't transfer to an unseen station. Random-CV numbers move by a similarly small, non-systematic amount (R2 0.634 -> 0.635, within-R2 0.206 -> 0.204).
