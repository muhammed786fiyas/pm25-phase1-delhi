# Archived station rosters

`cpcb_stations_delhi_status_manual.csv` is the hand-curated Delhi roster used for
all Phase 1 results up to tag `delhi-phase1-complete`. Its `qc_note` column
records why each station was kept or dropped.

From 2026-09-17 the roster at `data/stations/cpcb_stations_delhi_status.csv` is
generated by the pipeline (`cpcb_screen_stations` + `cpcb_finalize_roster`) from
rules, plus the hand-written `cpcb_station_overrides_delhi.csv`. The rules
reproduce this file's 42 KEEP stations exactly; only the DROP reason labels
differ. See `docs/logs/tasks/11-Pipeline_Reproducibility.md`.

This copy is kept for its human-written notes. Nothing in the pipeline reads it.
